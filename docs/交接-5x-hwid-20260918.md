## hwid_lock.c 选型（重要）

用 `GKI_KernelSU_SUSFS-hwid/hwid/hwid_lock.c`（5-key + hwid_match 宽容比对 + DRY_RUN），**不用** `oppo_oplus_realme_sm8650-hwid` 的 2-key 版：
- 2-key 版 `#include <linux/panic.h>` —— 5.10/5.15 树无此头（6.x 才拆分出来），会直接编译失败
- 5-key 版只用 `kernel.h`（panic/panic_timeout 在 5.10/5.15 的 kernel.h 里，已实测）

## 加设备流程

1. 设备端（原厂内核）跑 `sh hwid/probe_hwid.sh [预期id]` → `/sdcard/hwid_probe.log`
2. 取**原始值**（不要信识别脚本格式化输出），确认来源 key
3. 填 `hwid/allowlist.txt`（`^[0-9a-z._:-]{4,128}$`，超长 ID 必须原值逐字符一致）
4. 提交推送 → 触发构建 → 刷入前确认设备在 allowlist（不在会 panic 不开机）
