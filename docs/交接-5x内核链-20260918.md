排障要点（新增经验）：
- **LTO 阶段的 runner 回收是可复现的，不是玄学**：三轮 14 次 sm8550 全在 `LTO vmlinux.o` 后 8-10 分钟死，且日志显示被杀时编译一切正常（无 error）。FULL LTO 单进程峰值内存 20GB+ 超出 runner 16GB，GitHub 看门狗发 shutdown signal 优雅终止。**判据：`make[...]: *** [vmlinux] Terminated` + `runner has received a shutdown signal`，且之前无 error。**
- **5.10 树没 LTO 问题是因为它跑不了 LTO**：Kconfig `HAS_LTO_CLANG depends on AS_IS_LLVM`，5.10 Kbuild 用 -fno-integrated-as（需 GNU as）→ AS_IS_LLVM=n → LTO 被丢弃 → 普通 `LD vmlinux.o`（2 秒过）。
- **"更具体优先"规则**：`-Werror=strict-prototypes`（具体正）优先于 `-Wno-error`（通用负）无论位置；要关必须用 `-Wno-error=strict-prototypes`（具体负）且放在后面。
- **YAML 块标量里不能用 heredoc**：`run: |` 块里 heredoc 终止符无法顶格（YAML 缩进决定），bash 会吞掉后续脚本。用 `printf '%s\n' ... >> file` 单行追加。
- **空 ccache 陷阱**：失败 run 也会存 ccache（save 条件 `ccache_update || cache-hit != 'true'`），存的是半成品小缓存；下轮命中它（cache-hit=true）且 ccache_update=false → save 被跳过 → **永远存不上全量缓存**。修复：删空缓存（`gh cache delete <id>`）。
